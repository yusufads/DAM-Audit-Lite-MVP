# DAM Audit Lite Lead Magnet Flow v1.0

## Purpose

This document defines the acquisition, conversion and lead generation flow used by DAM Audit Lite.

The primary objectives are:

1. Generate qualified GEO leads
2. Collect Digital Perception Dataset records
3. Educate brands about AI visibility
4. Create demand for Full DAM Audit services

## Goal

* Website
* Industry

* Company Size
