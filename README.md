# DAM Audit Lite

DAM Audit Lite is a lightweight assessment tool based on the GEO-DAM Framework.

The tool evaluates a brand's Digital Perception Readiness across five dimensions:

- Entity Presence
- Authority Signals
- Knowledge Layer
- AI Visibility
- Perception Layer

The output is a DAM Score, a PDF report and structured dataset records.

Version: 1.0
Status: MVP

GEO-DAM is an open framework for measuring Digital Perception Readiness in the age of AI search and generative discovery.
