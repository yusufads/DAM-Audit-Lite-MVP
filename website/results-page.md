# DAM Audit Lite Results Page Specification v1.0

## Purpose

The Results Page is the most important screen in the DAM Audit Lite experience.

Its purpose is to:

* Deliver value
* Create insight
* Generate curiosity
* Convert users into GEO leads

The objective is not to sell.

The objective is to make the user want deeper analysis.
